1️⃣ Pattern già esistente: “Reset Assegnazioni”

Nel progetto stai già usando questo schema (semplificato):

const [isLoading, setIsLoading] = useState(false);

const handleReset = async () => {
  setIsLoading(true);
  try {
    await resetAssignments();
  } finally {
    setIsLoading(false);
  }
};


e nel bottone:

<Button disabled={isLoading} onClick={handleReset}>
  {isLoading && <RefreshCw className="mr-2 h-4 w-4 animate-spin" />}
  Reset Assegnazioni
</Button>


👉 Questo è il pattern da replicare ovunque

2️⃣ Regola generale da applicare a TUTTI i pulsanti

Ogni pulsante deve avere:

uno state boolean dedicato

disabled={isLoadingX}

icona animate-spin mentre lavora

testo invariato (oppure opzionalmente “In corso…”)

7️⃣ (Opzionale ma consigliato) → helper riutilizzabile

Se vuoi pulire il codice, puoi creare:

function LoadingButton({
  loading,
  children,
  ...props
}: ButtonProps & { loading: boolean }) {
  return (
    <Button disabled={loading} {...props}>
      {loading && <RefreshCw className="mr-2 h-4 w-4 animate-spin" />}
      {children}
    </Button>
  );
}


e poi:

<LoadingButton loading={isAssigning} onClick={handleGenerateAssignments}>
  Assegna
</LoadingButton>
