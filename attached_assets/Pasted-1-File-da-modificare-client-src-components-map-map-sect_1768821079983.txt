4) Calcolo offset “sempre visibile” (in pixel) per i task collaborativi

Dentro il forEach(tasksWithCoordinates.forEach(...)), dopo che determini collaborator_ids e assignedCleaner, aggiungi questa logica.

Inserisci/assicurati di avere:
const collaboratorIds = (task as any).collaborator_ids as number[] | null;
const assignedCleaner = (task as any).assignedCleaner as number | null;
const isCollaborativeTask =
  collaboratorIds && Array.isArray(collaboratorIds) && collaboratorIds.length > 1;

// offset in pixel (costante sullo schermo)
let collaboratorPixelOffsetX = 0;
let collaboratorPixelOffsetY = 0;

if (isCollaborativeTask && assignedCleaner) {
  const collaboratorIndex = collaboratorIds.indexOf(assignedCleaner);
  if (collaboratorIndex >= 0) {
    const totalCollaborators = collaboratorIds.length;
    const spreadPx = 28; // distanza fissa tra marker a schermo
    collaboratorPixelOffsetX =
      (collaboratorIndex - (totalCollaborators - 1) / 2) * spreadPx;
    collaboratorPixelOffsetY = 0;
  }
}


📌 Nota: questo è il punto chiave per “non si sovrappongono anche senza zoom”.

7) Dentro il CustomMarker: applica offset in pixel + disegna la linea

Se hai già la classe CustomMarker extends google.maps.OverlayView, devono esserci queste 3 cose:

A) Campi nuovi nella classe:

pixelOffsetY: number;

e nel constructor:

this.baseLatLng = new window.google.maps.LatLng(position.lat, position.lng);

B) In onAdd() crea la Polyline se collaborativo:
if (isCollaborativeTask) {
  this.polyline = new window.google.maps.Polyline({
    map: googleMapRef.current,
    path: [this.baseLatLng, this.baseLatLng],
    strokeColor: '#6B7280',
    strokeOpacity: 0.9,
    strokeWeight: 2,
    clickable: false,
    zIndex: isHighlighted ? 999 : 1,

C) In draw() applica l’offset pixel e aggiorna la linea:
const pos = overlayProjection.fromLatLngToDivPixel(this.baseLatLng);
if (!pos) return;

const x = pos.x + this.pixelOffsetX;
const y = pos.y + this.pixelOffsetY;

this.div.style.left = `${x - markerScale}px`;
this.div.style.top = `${y - markerScale}px`;

if (this.polyline) {
  const endLatLng = overlayProjection.fromDivPixelToLatLng(
    new window.google.maps.Point(x, y)
  );
  if (endLatLng) {
    this.polyline.setPath([this.baseLatLng, endLatLng]);
  }
}

D) In onRemove() rimuovi la linea:

  this.polyline.setMap(null);
  this.polyline = null;
}
